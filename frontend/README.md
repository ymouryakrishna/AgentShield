# AgentShield Frontend

> **React + Vite + Tailwind CSS Dark Fintech Interface for AI Commerce**

## Architecture Responsibilities
- 30-Second Judge Demo Center (`/demo`)
- Merchant Metrics & Revenue Story Dashboard (`/dashboard`)
- Conversational AI Buyer Interface (`/ai-buyer`)
- 3-Column Live Negotiation Arena with Policy Envelope Gauge (`/negotiation`)
- Commerce Firewall Inspector & Payload Tester (`/firewall`)
- Cryptographically Sealed Receipts Hub & Receipt Details (`/receipts`, `/receipt/:id`)
- Searchable Chronological Audit Timeline (`/audit`)
- Machine-Readable AI Catalog (`/products`)
- Merchant Policy Studio (`/policies`)
- Razorpay Test Mode Checkout Modal (Client UI only — secrets remain strictly in backend)

## Setup & Run
```bash
npm install
npm run dev
# App listens on http://localhost:5173
```
